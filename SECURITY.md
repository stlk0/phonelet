# Security policy

Report vulnerabilities through this repository's GitHub **Security → Report a vulnerability**
(Private vulnerability reporting). Include the affected revision, impact and reproduction steps;
redact credentials, phone numbers and message contents. Do not post vulnerabilities in public issues.

This policy covers the code in this repository, including its chan_dongle patches. Report issues
in upstream Asterisk or chan_dongle to their maintainers through their security reporting channels.

Known limitations are documented in [Security limits](docs/sms-commands.md#security-limits)
and [Operations: limitations](docs/operations.md#limitations).
